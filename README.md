# 🏥 Hospital Management System - Java Console Application

A comprehensive **Java-based console application** designed to simulate the core operations of a hospital or healthcare facility. This system includes functionality for managing patients, appointments, medical records, billing, inventory, and staff — ideal for learning Java and object-oriented programming in a real-world context.

---

## 🚀 Features

### ✅ Patient Management
- Register new patients with personal and contact details
- Retrieve patient information by ID

### 📅 Appointment Scheduling
- Assign appointments between patients and doctors
- Lookup appointment history

### 📋 Electronic Health Records (EHR)
- Add and view patient medical records
- Track visit history and treatments

### 💵 Billing & Invoicing
- Generate and store bills for patients
- Retrieve billing information and payment status

### 🏬 Inventory Management
- Add, update, and view medical supplies
- Monitor available quantities

### 👨‍⚕️ Staff Management
- Store and retrieve staff data (doctors, nurses, technicians, etc.)
- Track department and roles

---

## 🛠️ Technologies Used

- **Java SE 8+**
- **Object-Oriented Programming**
- **Java Collections Framework**
- **Console Input/Output (Scanner)**
